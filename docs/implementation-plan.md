# 사용자 웹 구현 계획

## 연결 흐름

1. 정품 Java 계정으로 접속한 사용자가 Velocity에서 개인별 일회용 URL을 받습니다.
2. 웹은 URL에 담긴 연결 요청을 API에 전달하고 만료 여부를 확인합니다. URL을 열었다는 사실만으로 계정을 연결하지 않습니다.
3. 사용자는 학교 로그인 전에 연결할 Minecraft 계정과 API가 제공한 개인정보 안내를 확인하고, 미선택 상태의 필수 동의를 직접 선택합니다. 로그인 시작 요청은 동의 버전과 연결 문맥을 API에 전달합니다.
4. API가 학교 SSO 흐름과 학적 검증 후 해당 연결의 웹 확인을 처리합니다. 이미 로그인한 회원은 대상 계정 확인과 동의를 한 번에 제출하며, 이후 화면은 게임 접속 확인 중으로 바뀝니다. 연결 확인이 실패해도 유효한 학교 세션을 보존합니다.
5. Velocity가 현재 정품 계정 접속을 확인하면 API가 연결을 확정하고, 허용된 로비로 이동합니다. 수동 명령은 게임 측 복구 수단으로만 남깁니다.
6. 웹은 기존 inspect API를 2초 간격으로 직렬 조회하고 연결 완료 시 조회를 중단합니다. 회원·서버 상태를 한 번 갱신하며 게임 입장 완료 여부를 추정하지 않습니다.

기존 학교 인증 성공과 변경된 자동 연결 흐름의 검증 범위는 검증 기록에서 구분합니다. 이 문서의 설계만으로 실제 게임 입장이 확인되었다고 간주하지 않습니다.

| 화면 | 표시할 정보와 동작 |
| --- | --- |
| 연결 시작 | 대상 Minecraft 계정과 스킨, 만료 상태, 개인정보 안내·필수 동의, 학교 인증 버튼 |
| 연결 확인 | 학교에서 확인한 최소 정보, 대상 계정 확인, 자동 연결 상태와 실패 복구 안내 |
| 내 계정 | 회원 자격, Minecraft·Discord 연결 상태, 허용 서버 |
| Discord 연결 | 봇이 확인한 계정, 동의·학교 로그인, 연결과 실제 역할 상태 구분 |
| 오류·대기 | 만료, 이미 연결됨, 명부 미등록, 정지, 외부 서비스 장애 |

## 인증·데이터 경계

- HttpOnly 세션을 사용하고 API 변경 요청에 CSRF 방어를 적용합니다.
- 로그인 세션이나 학교 토큰을 localStorage에 저장하지 않습니다.
- 일회용 URL에 포함된 비밀값이 리퍼러·분석 로그에 남지 않도록 하고, 링크 확인 후 주소에서 제거하는 흐름을 API와 합의합니다.
- Discord 봇이 발급한 호출자 전용 링크를 사용합니다. 사용자 입력 ID를 연결·역할 근거로 취급하지 않으며 이전 수동 입력·삭제 UI는 제공하지 않습니다.
- Discord 연결 실패가 학교 세션을 제거하지 않습니다. 계정 변경·해제는 관리자에게 문의하며, 연결 완료와 역할 반영 결과를 별도로 표시합니다.
- 사용자가 제출한 학번·권한 값은 신뢰하지 않습니다. 최종 상태는 API 응답에서만 가져옵니다.
- 학교 검증과 회원 명부 매칭은 별도 결과로 표현합니다.
- 개인정보 안내가 누락되면 로그인·연결을 차단하고, 서버가 버전 불일치를 반환하면 최신 안내를 불러와 동의를 해제합니다. 동의 기록과 보관 정책은 API가 관리합니다.
- 스킨은 같은 출처 API의 PNG data URI를 canvas로 그리며, 외부 아바타 서비스로 사용자 IP를 전송하지 않습니다. 스킨 오류는 인증 흐름을 차단하지 않습니다.

## 구현 완료 조건

- 웹 최종 확인만으로 Minecraft 연결이 활성화되지 않습니다.
- 만료되거나 이미 사용한 링크는 재사용할 수 없습니다.
- 명부 미등록자에게 회원 서버 접근 가능 상태를 표시하지 않습니다.
- 봇·학교 검증을 마친 Discord 연결만 표시하고, 역할 지급 완료는 API의 실제 `granted` 상태에서만 표시합니다.
- 실제 API와의 세션·CSRF·오류 처리를 확인한 뒤 실행 가능 상태로 문서를 갱신합니다.

React·Vite 앱에 실제 학교 로그인 시작 API, 학교 화면 이동, 콜백 오류 안내, 학교 인증 만료 갱신을 연결했습니다. `university` 모드에서는 개발용 로그인과 개발 표시가 나오지 않습니다. 회원 자격은 학교 학적 라벨이 아닌 API의 회원 명부 상태를 사용하고, 만료·정지 결과도 반영합니다. 실제 계정의 학교 콜백 왕복과 운영 Minecraft 연결 성공 여부는 [검증 기록](verification.md)에 별도로 기록합니다.
