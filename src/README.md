# 소스 구성

- `main.tsx`: React 진입점
- `App.tsx`: 실제 API 응답에 기반한 화면과 상호작용
- `api.ts`: 같은 출처의 API 호출, 오류 처리와 최소 타입
- `auth.ts`: 학교 로그인 주소 검증, 콜백 오류 안내와 회원 접근 상태
- `link.ts`: 최초 URL에서 연결 fragment와 안전한 오류 코드를 읽고 주소 정리
- `link-polling.ts`: 연결 상태 직렬 조회, 탭 숨김·만료·중단 처리와 늦은 응답 배제
- `ui.tsx`: 로그인 브랜드, 개발 표시와 공통 앱 레이아웃
- `styles.css`: 반응형 화면 스타일

학교 자격 증명이나 API 서비스 비밀값은 브라우저 코드에 포함하지 않습니다.

Discord 역할은 처리 중이거나 실패한 역할이 없을 때 한 줄의 완료 상태로 표시합니다. 학교 인증 역할이 회수되었거나 추가 관리 동의가 필요한 상태는 완료로 표시하지 않습니다. Minecraft 미연결 안내는 접속 가능한 서버 목록 위에 표시하며, 서버 목록에는 API가 반환한 접속 가능한 서버만 포함합니다.

`StatsView.tsx`는 로그인한 본인만 볼 수 있는 `/me/stats` 경로에서 누적 플레이 시간·블록·피해·죽음·몹 처치 기록을 서버별 또는 전체로 표시합니다. 공개 통계 화면은 제공하지 않습니다. `GameConsentNotice.tsx`는 API의 `privacyConsent.accepted`가 거짓이면 새 동의를 기본 해제 상태로 받습니다. 동의를 갱신하지 않은 계정의 실제 게임 기능 허용 여부는 API 정책으로 확인합니다.
